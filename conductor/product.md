# Initial Concept
Native iOS app (SwiftUI + SwiftData) with local LLM inference via `llama.cpp`.

# Synaps Notes (iOS) - Product Guide

## Vision
To provide a private, high-performance, and versatile note-taking experience for iOS users, leveraging local AI to enhance productivity without compromising data security.

## Target Audience
- Privacy-conscious individuals seeking secure note-taking solutions.
- Power users who require advanced text processing and search capabilities.
- Developers and tech enthusiasts interested in local LLM performance.

## Core Features
- **Local AI Chat:** Private interaction with documents and notes using `llama.cpp` for inference.
- **RAG (Retrieval-Augmented Generation):** Enhancing AI responses with context from the user's personal knowledge base.
- **Knowledge Base Ingestion:** Support for various document formats with high-quality text extraction.
- **Apple Vision OCR:** Reliable text recognition for images and scanned documents.
- **Cloud Sync & Backup:** Secure synchronization using Google Drive and robust backup mechanisms.
- **SwiftData Persistence:** Modern, reactive data management for notes and configuration.
